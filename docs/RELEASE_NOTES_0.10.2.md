# TermuxPro v0.10.2 发布说明（草稿，冻结时定稿）

## 版本类型
补丁版（全部为体验修复与治理，无新增功能）。本页自 0.10.2-rc.1 候选说明定稿，候选与稳定版内容一致。

## 修复与体验改进（自 v0.10.1）

### 隐私表述精确化（延续 0.10.1 后的 AI 会话中心治理）
- 工作区首页安全提示、AI 会话中心摘要、终端搜索说明、README 与 UX 检查表的"AI 历史/私有历史"表述全部精确为"Claude/Codex 历史"；静态门禁新增变体禁用并纳入文档扫描，防止回退。

### 无效工作区错误态可恢复
- 远端文件、文件预览、项目任务、连接诊断、Git 工作台、tmux 管理六个页面的"工作区连接信息无效"死胡同文案，统一改为列明缺失项（SSH 地址/端口/项目目录）并指向"返回工作区补全"；无效态下刷新按钮统一禁用并降低透明度，不再误导点击。

### 大字体与无障碍
- 200% 字体下终端顶部工具按钮切换"历史/TUI"极简变体（完整语义保留在无障碍描述），SSH 地址提示收敛为"user@host 或 ssh…"，消除截断。
- 终端会话列表兜底标题资源化（未知会话），中文界面不再漏出英文。
- 终端工具栏文本输入补 hint，首用者可见输入用途。
- SSH 公钥页空态下"复制公钥/安装到服务器"按钮明显禁用视觉（透明度 0.4），避免误点必失败操作。

### Git 工作台信息降噪
- 状态摘要不再复述"推荐动作"，同屏最多一处下一步入口（状态自适应主按钮 + 建议区）；清理 8 个无引用字符串。

### 交付流程治理
- auto-dev-pr 修复批量推送下模拟器 UI 等待死锁；job 预算 60→120 分钟适配冷缓存。
- 8 个游离静态门禁纳入 test-all.sh，由 CI 强制执行。
- 非 Codex 驱动的额度门禁通道，托管切换不再产生假阻塞。

## 已知限制
- 16 个上游 termux-app 提交待同步（无安全级紧急项；含 TermuxOpenReceiver NPE 修复、多窗口边距闪烁修复、Sixel/位图终端支持），安排在 v0.10.2 发布后作为独立兼容守护切片。
- 涉及触摸滚动、软键盘与厂商 ROM 行为的变更仍建议真机复验（本版无此类底层变更）。

## 体验验证建议（重点场景）
1. 首次配置 SSH 到进入远端文件页：故意填错端口，确认错误态列明缺失项且可返回工作区补全。
2. 系统字体调至 200%：工作区首页与终端顶部按钮完整可读。
3. SSH 公钥页无密钥时：确认"复制/安装"按钮明显不可用。
4. Git 工作台有改动时：确认"按文件审查"只出现一次主入口。
