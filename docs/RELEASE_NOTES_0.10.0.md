# TermuxPro 0.10.0 正式版发布说明

`0.10.0` 基于 `0.10.0-rc.1` 候选版转为稳定版。本版本不在候选范围外新增功能，只完成稳定发布、签名
APK、附件校验和 `master` 交付闭环。

本版本继续只打磨 TermuxPro 增值层：SSH 远程开发、Claude Code / Codex CLI 使用体验、tmux/Git 可视化
管理、自定义快捷指令和移动端交互；Termux 原始终端、PTY、本地 shell、包管理、基础会话和基础快捷键
只做兼容回归，不重复造轮子。

## 主要变化

- AI CLI 会话中心优化 200% 字体和窄屏层级，四个核心入口“新建/历史 Claude、Codex”保持首屏可扫读。
- tmux 会话中心在大字体下优先展示当前工作区和可操作会话，其他归属只读管理，降低共享账号误操作风险。
- 工作区首页把抽象“高级设置”改为“tmux 连接方式”，直接说明连接后是否进入 tmux、默认会话名和共享账号风险。
- Git 提交前确认框新增当前分支与 `host:port · path`，避免多服务器/多项目场景下误提交。
- AI 启动前新增风险摘要：点击 Claude/Codex 前即可看到本次启动只建立 SSH，不自动进入 tmux 或恢复历史。
- 自动研发 PR 的 Actions 可见步骤改为“创建 PR、等待门禁、合并并验证 dev”，并写入 Step Summary。

## 验收重点

1. 稳定 APK 必须完成 `0.9.7 → 0.10.0` 覆盖升级验收。
2. `versionCode=100002` 必须高于 `0.10.0-rc.1` 的 `100001`。
3. Claude/Codex 快捷启动必须始终只建立 SSH，不自动进入 tmux、不自动恢复历史、不读取 AI 私有历史。
4. Git 提交确认必须展示当前分支和远程目标，且只提交已暂存内容，不推送、不自动暂存、不丢弃工作区文件。
5. Release 必须是非草稿、非预发布，附件包含 APK、`SHA256SUMS` 和 `APK_SIGNATURE.txt`。
6. 原始 Termux 终端、PTY、本地 shell、基础会话和基础快捷键语义不得被 TermuxPro 增值层修改。

## 已知限制

- 本版本仍不读取 Claude/Codex 内部历史文件；历史选择继续交给 CLI 原生选择器。
- Git 工作台仍保持安全优先：不提供 force push、硬重置、自动 rebase/merge 或删除远端分支。
- 本地共享服务器 KVM 不可用，稳定 APK 的覆盖升级与截图验收依赖 GitHub Runner 隔离模拟器。

## 安装提醒

- 包名仍为 `com.termux`，与其他签名来源的 Termux 不能直接覆盖安装。
- 升级前请备份重要本地 Linux 环境和配置；卸载应用会删除应用私有数据。
- 如果已安装 `0.9.7` 正式版、`0.9.9-rc.1` 或 `0.10.0-rc.1` 候选版，可直接覆盖升级到本版本。
