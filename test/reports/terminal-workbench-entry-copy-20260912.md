# 终端工作台入口文案验收记录（2026-09-12）

## 背景

用户曾反馈终端页面进入移动开发工作台的入口不够直观。主动走查发现，顶栏短标签使用“远程配置”容易被理解成一次性设置页，而不是随时返回的移动开发工作台；这会降低用户在终端、AI CLI、Git/tmux 工具之间往返的可发现性。

## 本轮改动

- 顶栏短标签由“远程配置”改为“工作台”，降低理解成本。
- 英文短标签由 “Remote setup” 改为 “Workbench”，与中文语义一致。
- 无障碍说明保留完整语义：返回移动开发工作台，管理服务器、项目目录、AI 入口和连接策略。
- 不新增按钮，不改变原始终端、会话抽屉、SSH 连接、AI CLI、Git 或 tmux 行为。

## 主动发现候选

1. 终端顶栏“远程配置”偏静态设置语义，用户可能不知道它可随时回到移动开发工作台；本轮推进。
2. 顶栏短标签必须克制，不能回退为长句挤压 AI/工具箱入口；完整说明放在 `contentDescription`；本轮推进。
3. 工作台、AI、工具箱三入口后续仍需持续观察 200% 字体和窄屏下的优先级；本轮暂不增加控件，避免制造首页/顶栏噪声。

## 验收重点

- 终端顶栏可见文本为“工作台”，更符合用户“返回工作台”的心智。
- 无障碍描述仍能说明它管理服务器、项目目录、AI 入口和连接策略。
- 该变更只作用于 TermuxPro 增值入口，不影响官方 Termux 原始终端能力。

## 回归修正

- 首次远端模拟器验收失败于 `UiRenderingInstrumentedTest.captureCriticalDarkPages`，原因是仪表测试仍断言旧文案“远程/配置”，不是页面渲染或截图集合退化。
- 已同步 Android 仪表测试断言：可见短标签检查“工作台”，无障碍描述检查“服务器”和“AI”，避免测试与产品文案脱节。
