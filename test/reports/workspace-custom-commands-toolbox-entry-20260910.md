# 首页工具箱补充快捷指令入口回归

## 背景

- 来源：用户反馈 `0.10.0` 暴露首页控件堆叠、工具入口不直观、自定义能力不足。
- 增值服务分类：自定义快捷指令、远程工作区、移动端交互体验、上下文工具箱。
- 负责人主动复核：`CustomCommandsActivity` 已具备按工作区管理能力，但首页工具箱没有直接入口，用户需要从终端或 AI 会话中心绕路。

## 本轮调整

1. 已保存工作区展开“工具箱”后，展示全宽“快捷指令”入口。
2. 点击入口只打开 `CustomCommandsActivity` 管理页，不自动执行任何命令。
3. 工具箱说明补充快捷指令，避免用户误以为工具箱只包含 Git/tmux/文件/诊断。
4. 大字体布局不新增双列压缩压力；快捷指令入口独立占满一行。

## 验收范围

- Robolectric 覆盖：
  - 已配置工作区默认仍隐藏工具箱内容。
  - 用户主动展开后能看到“快捷指令”入口。
  - 点击“快捷指令”会进入 `CustomCommandsActivity`。
- 本轮不启动模拟器：当前远程环境 KVM 不可用，模拟器验收不能作为本切片的即时门禁。
- 设备验收要求：后续候选/正式发布前，需要在模拟器或 Android 真机上确认工具箱展开、入口点击、返回路径和 200% 字体可读性。

## 风险控制

- 不修改 SSH 连接命令。
- 不修改 tmux 归属或恢复策略。
- 不读取 Claude/Codex 私有历史。
- 不触碰真实远程服务器会话。
