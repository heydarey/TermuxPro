## 产品与安全边界

- 增值层：帮助手机用户在 Git 工作台内快速定位最近提交，减少手输 `git log | grep`。
- 非目标：不实现远端全文搜索、不读取更多历史、不切换分支、不提交、不推送。
- 安全：筛选仅在内存中处理已脱敏的提交哈希、相对时间和标题；点选后仍复用既有安全哈希校验读取详情。
