# Android 验收证据分级规则

## 背景

用户质疑“当前服务器 KVM 不可用，本轮只跑低资源 JVM/Robolectric/静态验证，不启动模拟器”是否还能算验收。结论是：不能算完整验收，只能算低资源自动化验证。

## 本轮规则补充

1. `docs/DEVICE_ACCEPTANCE.md` 新增验收分级：
   - 低资源验证。
   - GitHub Runner 模拟器验收。
   - 发布级 APK 验收。
   - 结论用语必须匹配证据。
2. `AGENTS.md` 明确：
   - 无 KVM 共享服务器不得强行启动本地 Android 模拟器。
   - 低资源验证必须写明“待设备验收”。
   - 普通研发 PR 使用 GitHub Runner 隔离模拟器补 Android 运行时证据。
   - 候选/正式版本必须有 APK 安装级证据。

## 风险控制

- 不修改构建脚本。
- 不修改 CI。
- 不影响用户级或系统级配置。
- 不启动模拟器、不触碰真实 tmux。
