# 快捷指令导入备份回归记录（2026-09-11）

## 背景

“复制备份 JSON”解决了快捷指令的导出和复盘，但如果没有导入能力，用户换机、重装或在多个工作区复用命令时仍需要手工复制。该场景属于自定义快捷指令的完整生命周期，不应依赖用户自己在终端里维护配置文件。

## 本轮改动

- 快捷指令页新增“从剪贴板导入 JSON”，有效工作区下始终可用；无效工作区隐藏。
- 导入前解析剪贴板中的 `termuxpro.customCommands.v1` 备份，限制单次最多 100 条。
- 导入前弹出深色确认框，明确来源工作区、目标工作区、导入条数和“不执行远端命令”。
- 导入时继续复用快捷指令校验器，拒绝空命令、超长内容和疑似 Token/密码/私钥等敏感命令。
- 与现有指令重名时自动追加“（导入）/（导入 2）”后缀，避免覆盖用户已有配置。

## 验收点

- 点击导入后只展示确认弹窗；确认前不会写入本地存储，也不会启动 `TermuxActivity`。
- 确认导入后指令保存到当前工作区，而不是备份里的源工作区。
- 已存在同名指令时，导入指令自动重命名，避免覆盖。
- 剪贴板内容无效或包含疑似敏感命令时，展示页面内深色反馈，并拒绝保存。

## 后续观察

- 若用户后续需要更强的迁移能力，可增加“导入预览列表”和“按条勾选”，但必须继续保持确认前不落盘、不执行。
- 可考虑在工作区管理页提供“工作区级备份/恢复”，统一包含连接元数据、tmux 策略、AI 启动记录和快捷指令，但不得导出密码、私钥或终端输出。
