# Git 提交记录上下文验收报告（2026-09-09）

## 增值服务准入

- 分类：Git 可视化、远程工作区、移动端工作流效率。
- 非目标：不实现新的 Git 写操作，不改变 `git log`/`git show` 远端命令，不重做 Termux 原始终端能力。
- 安全边界：本轮只增强提交记录弹窗的上下文说明，帮助用户确认当前仓库目标。

## 产品问题

多服务器、多项目和 AI 修改检查场景中，开发者经常从终端工具箱直接打开 Git 工作台。提交记录弹窗原来只
提示“只读”，没有再次展示当前分支和远程目标。用户在手机上切换工作区或从 AI 会话返回后，容易把另一个
服务器/项目的提交记录误认为当前项目。

## 实现

- 提交记录弹窗增加：
  - 当前分支
  - 当前目标：`host:port · path`
- 保留原有只读说明：查看提交详情不会切换分支、提交或推送。
- 目标信息只来自 `GitDiffActivity` 启动参数，不读取或记录终端输出。

## 验收

- 产品验收：用户打开提交记录前即可确认“我正在看哪个远端项目、哪个分支”。
- UI/UX 验收：上下文在弹窗说明区域，不增加额外按钮，不干扰提交列表选择。
- 架构验收：不新增远端命令，不改变 Git 执行路径。
- QA 验收：`GitDiffActivityTest.commitHistoryUsesReadableSelectionAndExplainsReadOnlyDetails`
  锁定分支、目标和只读说明。
