## 发布门禁

1. `termuxpro-version.properties` 必须为 `0.10.1-rc.1` / `100101`，且发布说明文件存在。
2. `versionCode=100101` 必须高于 `0.10.0` 正式版的 `100002`。
3. 本地 `git diff --check`、Skill 校验、版本元数据校验、workflow 策略校验、Release APK 设备冒烟脚本和
   Release ABI 门禁必须通过。
4. 候选 PR 合入 `dev` 前，分支 CI 和必要的 Emulator UI 必须通过。
5. 候选 PR 合入 `dev` 后，merge commit 收尾 CI 必须通过。
6. 标签 `v0.10.1-rc.1` 必须由自动 PR 流水线在合并提交上创建，不覆盖既有标签。
7. Release workflow 必须创建公开 Pre-release，并完成正式签名 APK 构建、覆盖升级验收和附件校验。
