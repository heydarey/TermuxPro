# Git 工作台入口命名回归

## 背景

- 来源：用户反馈 Git 方面可支持的功能看起来太少，且入口不符合真实开发者痛点。
- 增值服务分类：Git 可视化、远程工作区、移动端工作流效率、上下文工具箱。
- 主动复核：Git 工作台已经提供当前分支、分支列表/创建/删除、stash、暂存/取消暂存、提交、fetch/pull/push、提交记录和按文件审查；但首页工具箱仍显示“Git 修改”，终端推荐区仍显示“Git 状态”，入口文案压窄了用户对功能范围的认知。

## 本轮调整

1. 首页工具箱 Git 总入口从“Git 修改”改为“Git 工作台”。
2. 终端工具箱推荐区 Git 总入口从“Git 状态”改为“Git 工作台”。
3. 终端项目区仍保留“审查 Git Diff”作为具体动作，避免用户需要看完整 diff 时找不到直达入口。
4. 只改命名和测试断言，不改变任何远端 Git 命令、不新增写操作。

## 验收重点

- 已配置工作区展开工具箱后，应看到“Git 工作台”。
- 终端工具箱推荐区应展示“Git 工作台”。
- Git 工作台内部已有能力不回退；本轮不重做 Termux 原始终端 git 命令。

## 当前限制

- 本轮验证以 JVM/Robolectric/静态门禁为主。
- 候选/正式发布前仍需模拟器或真机确认入口在默认字体和 200% 字体下可读、可点击。
