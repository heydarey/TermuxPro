# 多工作区目标辨识与管理操作验收

## 场景与问题

- 目标旅程是开发者在手机上从多个远程工作区中确认正确服务器与项目，再安全地打开远程终端或维护当前工作区。
- 旧版摘要与选择器只显示主机和目录；同一主机承载多个 SSH 端口时，用户无法仅凭界面判断将要连接的目标。
- 对象菜单此前叫“更多工作区操作”，且其中重复提供“新建工作区”。这既不能说明该菜单能做什么，也与页面上已经存在的“新建工作区”主操作重复。

## 体验修复

1. 工作区摘要及选择器统一展示 `主机:端口 · 项目目录 · 最近状态`，端口是远程身份的一部分，不能在移动端省略。
2. 仅保留页面上的“新建工作区”作为创建入口；当前对象菜单改为“复制或删除当前工作区”，让名称与实际、可逆的生命周期操作一致。
3. 未改变连接策略、SSH 认证、tmux 归属校验、工作区隔离或任何远端命令。该切片只改善本地 UI 的目标辨识与可发现性。
