# 工作区连接字段可读性审计

## 截图发现

- 核心旅程是首次在手机上粘贴或输入 SSH 连接信息，然后建立远程工作区。
- `termuxpro-emulator-ui-247` 修复前的 200% 字体截图显示，SSH 地址输入框只能依赖一条较长的占位文本表达语义，末尾被裁切；用户填写后，占位文本还会消失。
- 地址、端口与远程路径属于高风险且必须可辨识的输入，不能让用户凭输入顺序猜测字段用途。

## 修复设计

1. 为 SSH 地址、SSH 端口和远程项目路径提供常驻中文标签，输入框只保留简短示例。
2. 三个标签均通过 Android `labelFor` 关联对应输入框，确保 TalkBack 与自动化可识别字段语义。
3. 保留已配置工作区的摘要模式；仅在编辑/新建基础字段时展示标签，不增加首页信息密度。
4. Android 截图测试在初始工作区页等待布局空闲后，断言三个标签都有实际可见区域，防止后续大字体改动重新裁切。
