# 快捷指令复制备份回归记录（2026-09-11）

## 背景

TermuxPro 的快捷指令已经支持按工作区创建、编辑、复制、启停、排序、删除和运行确认。主动体验后发现：用户在手机上沉淀 Codex、Claude、Git、tmux 和项目测试命令后，缺少一个轻量方式把这些配置备份、迁移到另一台设备，或复制出来给 AI/团队复盘。

## 本轮改动

- 快捷指令页在当前工作区已有指令时显示“复制备份 JSON”入口；空列表和无效工作区不展示，避免首屏噪音。
- 点击后只读取 TermuxPro 本地快捷指令配置，复制 JSON 到剪贴板，不启动终端、不连接 SSH、不执行远端命令。
- 导出内容包含 schema、工作区 id/name/host/port/path 和指令的 name/command/workingDirectory/group/enabled/confirmation，不包含密码、私钥或终端输出。
- 操作完成后使用页面内深色反馈提示“已复制 N 条快捷指令 JSON”，继续避免系统 Toast 白块无字问题。

## 验收点

- 空快捷指令列表不显示备份入口，首屏仍以“选用模板 / 新建指令”为主。
- 已有快捷指令时入口可见，并带有无障碍说明，说明该操作只读取本地配置且不会运行远端命令。
- 点击备份入口后剪贴板 JSON 可解析，且保留当前工作区边界。
- 点击备份入口不会创建 `TermuxActivity` 启动 Intent，不会误执行任何 SSH/tmux/Git 命令。

## 后续观察

- 如果用户反馈有跨设备恢复需求，再设计“从 JSON 导入”能力；导入必须做 schema 校验、目标工作区选择、重复项预览和二次确认。
- 快捷指令后续继续按“主操作明确、二级操作可理解、危险操作可恢复”的标准复核。
