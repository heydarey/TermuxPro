# AI CLI 会话中心快捷指令入口语义验收（2026-09-11）

## 主动发现

- 旅程：开发者在手机上完成 Claude Code / Codex CLI 工作后，从 AI CLI 会话中心进入下一步整理、验证或复用命令。
- 证据：`AI 完成后` 区域里的入口文案为“管理快捷指令模板”，但实际打开的是完整快捷指令页，用户可查看、筛选、新建、复制、编辑、启停、删除和从模板预填，不只是“管理模板”。
- 影响：文案过窄会让用户误以为只能维护模板，忽略自定义快捷指令作为 AI 工作后复用验证命令的核心能力。
- 增值服务分类：AI CLI、自定义快捷指令、移动端工作流效率。

## 本轮调整

- 中文入口改为“快捷指令与模板”。
- 英文入口改为“Quick commands and templates”。
- 补充 AI CLI 会话中心回归断言，确保该入口继续打开快捷指令页。

## 验收标准

1. AI CLI 会话中心 `AI 完成后` 区域应明确表达这是完整快捷指令能力，而不是单一模板管理。
2. 点击入口仍进入 `CustomCommandsActivity`。
3. 该入口不会自动执行命令；命令执行仍由快捷指令页的确认流程控制。
4. 不改变 Termux 原始终端、PTY、本地 shell 或基础会话行为。
