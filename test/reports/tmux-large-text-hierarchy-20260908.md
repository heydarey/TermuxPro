# tmux 会话大字体信息层级审计

## 截图发现

- 目标旅程是开发者在手机上打开当前远程工作区的 tmux 列表，先判断会话归属，再进入、新建或管理自己的会话。
- 旧版 200% 字体截图把远端目标、安全说明、完整状态提示和每个会话的创建/活跃时间放在同一层级。首屏虽没有控件裁切，但“新建会话”和首个可操作会话被低优先级文本挤压，用户需要额外滚动和阅读才能判断下一步。
- 共享远端账号下，列表最重要的信息是会话名称、当前工作区归属、窗口数与连接状态；时间信息应保留，但不应妨碍先作出安全选择。

## 修复设计

1. 200% 字体时把操作提示收敛为“点击会话进入；当前工作区会话可管理”，同时向辅助技术保留完整的重命名/停止边界说明。
2. 大字体列表行优先展示名称、窗口数、连接状态和归属；创建/活跃时间仍在常规字体显示，避免牺牲默认密度。
3. 当前工作区归属明确标记为“当前工作区 · TermuxPro 创建”，避免把“TermuxPro 创建”误理解为可管理所有会话。
4. 真实 Android 截图测试断言状态、新建会话以及列表首项在初始视口有可见区域；归属控制逻辑、只读外部会话与危险停止确认均未改变。
