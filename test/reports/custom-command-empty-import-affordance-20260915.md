# 快捷指令空态导入语义验收记录

## 切片目标

快捷指令页是 TermuxPro 的增值服务，用来把用户在手机上反复输入的 Git、tmux、AI CLI、测试和发布命令沉淀
为可复用入口。空列表时用户最需要的是“选模板 / 新建 / 从旧设备导入”，不是理解一个泛化的“备份与迁移”。

## 主动发现记录

| 观察 | 来源 | 影响旅程 | 增值服务准入 | 结论 |
| --- | --- | --- | --- | --- |
| 当前工作区没有快捷指令时，顶部仍显示“备份与迁移”，但弹窗只提供导入。 | 负责人 UI 代码走查 `CustomCommandsActivity` | 首次进入快捷指令页，用户判断下一步 | 自定义快捷指令、移动端交互体验 | 本轮推进 |
| 空态已经有“选用模板 / 新建指令”，泛化迁移入口会和首次创建路径竞争。 | 产品旅程复盘 | 手机软键盘下减少决策和阅读成本 | 自定义快捷指令、移动端工作流效率 | 本轮推进 |
| 导入备份仍是有效空态路径，不能简单隐藏入口，否则跨设备迁移会变深。 | 架构/体验取舍 | 换机或多设备同步快捷指令 | 远程工作区、自定义快捷指令 | 本轮保留入口但改语义 |
| 模板列表仍可继续按场景搜索/分类，但会扩大弹窗结构。 | Backlog 延续观察 | 首次创建模板选择 | 自定义快捷指令 | 暂缓，避免本轮堆更多控件 |

## 实现摘要

- 空列表时，快捷指令页顶部备份入口显示为“导入备份”。
- 空列表时，入口无障碍说明明确“确认前不会保存或执行远端命令”。
- 空列表弹窗标题改为“导入快捷指令备份”，说明只从剪贴板导入 TermuxPro 备份。
- 当前工作区已有快捷指令后，入口恢复为“备份与迁移”，继续提供导出/导入。

## 非目标

- 不改变快捷指令导入 JSON schema。
- 不自动执行导入命令，不保存 SSH 密码、私钥、Token 或终端输出。
- 不新增首页控件，不改变 Termux 原始终端、PTY 或基础会话行为。

## 验收标准

1. 空态按钮文案为“导入备份”，contentDescription 指向空态导入说明。
2. 空态点击后弹窗标题为“导入快捷指令备份”，列表只包含“从剪贴板导入 JSON”。
3. 保存第一条快捷指令后，按钮恢复为“备份与迁移”。
4. 有快捷指令时仍可复制备份 JSON，并且不启动终端或远端命令。
