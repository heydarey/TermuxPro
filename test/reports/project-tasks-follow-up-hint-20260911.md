# 项目任务运行后续接提示验收记录

## 背景

- 主动走查旅程：开发者在手机上通过“项目任务”运行远端测试或构建。
- 问题：页面已有任务会话摘要和“查看任务会话”入口，但确认运行弹窗只说明目标与命令；用户按下“运行任务”后，容易不知道应返回哪里继续看日志或管理 tmux。
- 增值服务分类：远程工作区、tmux 可视化、移动端工作流效率。

## 方案

1. 在项目任务运行确认弹窗中补充“运行后可回到本页点‘查看任务会话’继续看日志或进入 tmux 管理”。
2. 同一文案明确 TermuxPro 不会自动进入其他工作区任务会话，避免共享服务器、多工作区场景误入。
3. 不改变任务检测、命令构造、tmux 归属校验或 Termux 原始终端能力。

## 验收

- `ProjectTasksActivityTest.confirmationNamesRemoteTargetAndCommand` 断言确认弹窗继续展示远端目标、命令、新的持久终端会话。
- 同一测试新增断言确认弹窗包含“查看任务会话”和“不会自动进入其他工作区任务会话”。
- 后续推送后由 GitHub CI/必要的 Emulator UI 补 Android 运行时回归。
