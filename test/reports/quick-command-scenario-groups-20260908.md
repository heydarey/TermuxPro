# 快捷指令场景分组体验切片

## 背景

0.5.0 体验反馈指出：当 Git、tmux 或 AI CLI 内置操作覆盖不足时，用户无法按自己的工作流补齐动作。
当前 dev 已具备快捷指令 CRUD 与模板，但页面仍偏普通列表，缺少“它用于补齐哪些开发场景”的直接解释。

## 本轮改动

- 在快捷指令页面增加场景说明，明确快捷指令用于沉淀 Git、tmux、AI CLI、测试和发布等重复命令。
- 快捷指令列表按分组插入“xx 场景”标题，让用户在手机上能按开发场景扫读，而不是逐条阅读命令。
- 保持原执行协议不变：运行前仍展示目标和命令，危险命令仍二次确认，秘密检测仍阻止保存。

## 验收点

- 无指令时仍展示模板引导。
- 新增无分组指令后展示“未分组 场景”。
- Git 分组指令展示“Git 场景”，且安全指令仍可直接进入独立 SSH 会话执行。
- 不改变 Termux 原始终端、PTY、本地 shell 和基础会话行为。
