## 改动范围

- 导入备份二次确认文案新增目标摘要：当前工作区名称下方展示 `host:port · path`。
- 继续保留来源工作区、导入数量、最多 3 条指令名称和剩余数量摘要。
- 不改变导入解析、秘密检测、重名后缀、保存时机、执行策略或远程命令行为。

## 验收标准

- 在导入确认前，用户能同时看到来源工作区、目标工作区名称、目标服务器/端口/路径和即将导入的指令名称。
- 用户取消确认时不落盘、不执行远端命令。
- 用户确认后仍只保存本地快捷指令；重名仍追加“导入”后缀。
- 变更属于 TermuxPro 自定义快捷指令与远程工作区增值层，不触碰 Termux 原始终端、PTY、包管理或基础会话语义。

## 复盘

- 减少的真实负担：多服务器用户在手机上导入备份前无需靠记忆判断“移动端”这类名称对应哪台机器。
- 控件噪声：未新增按钮，只在已有二次确认中补一行目标摘要。
- 原始 Termux 能力：没有改变终端输入、滚动、PTY、本地 shell 或会话行为。
- 下一轮优先检查：快捷指令导入后的列表定位、模板分类和 AI/Git/tmux 工具入口是否还能进一步减少误解。
