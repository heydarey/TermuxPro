# Git 工作台大字体工具栏间距验收

## 场景与问题

- 开发者在远程项目中查看 Git 状态时，需要能一眼区分“Git 工作台”页面标题和“刷新”这一独立操作。
- 原 200% 字体截图中，标题与操作区过近，视觉上容易被读成一个连续词；这不是功能缺失，却会提高移动端扫读和误触成本。

## 体验修复

1. Git 标题使用受限的统一自动缩放（14sp–18sp），保留单行标题，不以无限缩小字体掩盖窄屏问题。
2. 标题两侧保留 8dp 内边距，“刷新”操作增加 8dp 起始间距；返回、标题和刷新仍分别保持独立可点区域。
3. 205dp 宽、200% 字体布局测试断言标题单行、启用统一自动缩放，且标题与刷新之间至少保留 8dp 间距。

- 对包含极长主机名和工作目录的 Git 目标行继续维持可读的换行节奏；不得通过缩小关键操作文字或挤压点击区来换取单行显示。
