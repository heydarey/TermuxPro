## 本轮范围

- 为终端工具箱的“项目任务 / 测试”菜单项补充内容描述。
- 描述明确：打开当前工作区的项目任务和测试页，先展示远端目标与命令，由用户确认后执行，不会直接输入当前终端。
- 同步中英文资源和 Robolectric 断言。

## 非目标

- 不新增项目任务类型。
- 不改变远端命令构造、SSH、tmux 归属校验或任务启动策略。
- 不研究或重做 Termux 原始终端输入、PTY、滚动和基础会话能力。

## 验收重点

1. 终端工具箱仍按推荐操作、当前终端、项目与 Git、连接与安全、AI 工作、键区切换分组。
2. “项目任务 / 测试”仍位于“项目与 Git”分组。
3. 无障碍描述必须说明入口只打开项目任务页，并在执行前展示目标与命令等待确认。
4. 该入口不得直接向当前 shell、Claude Code 或 Codex CLI TUI 输入命令。
