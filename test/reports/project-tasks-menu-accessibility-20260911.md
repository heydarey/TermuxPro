## 本轮范围

- 为终端工具箱主要菜单项补充内容描述，覆盖 AI CLI 会话中心、Git 工作台、tmux 管理、快捷指令、提示词编辑、搜索输出、触摸滚动、Git Diff、远端文件、项目任务 / 测试、Web 预览、环境诊断、SSH 密钥、AI 确认/返回、中断和键区切换。
- 描述明确区分三类行为：只打开页面、只切换本地状态、或向当前终端发送按键。
- 对有风险的入口说明边界：不会自动执行远端命令、不会自动授权 AI、不会保存密码/私钥、不会直接提交/拉取/推送、不会重命名或停止非当前工作区 tmux 会话。
- 同步中英文资源和 Robolectric 断言。
- 首次远端 Emulator UI 暴露 `workspace_prompt_description` 漏补导致编译失败；已补齐中英文资源并保留断言，避免同类入口说明只改 Java、不补资源。

## 非目标

- 不新增项目任务类型。
- 不改变远端命令构造、SSH、tmux 归属校验或任务启动策略。
- 不研究或重做 Termux 原始终端输入、PTY、滚动和基础会话能力。

## 验收重点

1. 终端工具箱仍按推荐操作、当前终端、项目与 Git、连接与安全、AI 工作、键区切换分组。
2. “项目任务 / 测试”仍位于“项目与 Git”分组。
3. 所有主要工具项都有菜单级内容描述，便于 TalkBack 和长菜单扫读。
4. 项目任务入口必须说明只打开项目任务页，并在执行前展示目标与命令等待确认。
5. AI 确认入口必须说明只发送 Enter 且应用不会自动授权。
6. Git/tmux/SSH Key 等入口必须说明只读或可管理边界，避免误以为会直接修改远端状态。
