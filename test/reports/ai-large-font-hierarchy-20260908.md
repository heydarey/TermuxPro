# AI CLI 会话中心大字体信息层级审计

## 截图发现

- 目标旅程是开发者在手机上确认当前远程工作区后，快速选择 Claude 或 Codex 的新建/历史入口；连接策略必须始终可理解，不能隐式恢复历史或进入 tmux。
- 旧版 200% 字体首屏同时展示“当前上下文”“执行目标”两个重复标签，以及完整的多行安全说明。目标名和主机路径已经足以解释当前对象，重复文本挤压了四个核心操作的扫读空间。
- 需要降低阅读密度，但不能削弱共享账号、历史会话或 tmux 的安全边界，也不能让辅助技术失去完整说明。
